# Face Detection
## Introduction:
This program allows real-time face detection through your personal webcam through the use of **OpenCV**. 
<br>Please note that the face detection is not perfect. 

## Instructions:
1. Clone this repo by using the following command in your desired repository:

    `git clone https://github.com/JSLee-24/face_detection.git`

2. Run by using the following command: 

    `python3 face_detector.py`

3. To exit, press `q` on the frame or `CTRL + C` on the terminal.
